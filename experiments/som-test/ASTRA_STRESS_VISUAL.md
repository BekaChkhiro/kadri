# Astra low / c_visual — stress და tracking ვიზუალური განხილვა

თარიღი: 2026-10-17. **AI ასისტენტის ვიზუალური განხილვაა**, არა ადამიანის დამოუკიდებელი ანოტაცია ან გაზომილი semantic accuracy. განხილულია ამ იზოლირებული checkout-ის snapshot; შემდგომ დამატებული შედეგები აქ არ იგულისხმება. API გამოძახებები: **0**. კოდი, შედეგები და ledger არ შეცვლილა.

ყველა საწყისი სცენა სინთეზურია; noise, blur, occlusion და მეზობელი კადრები იმავე მასალის ხელოვნური გარდაქმნებია. ეს რეალური კამერით ვალიდაციას, ვიდეოტრეკინგს ან production მზადყოფნას არ ამტკიცებს. `proxy.json`/IoU სემანტიკური სისწორის საზომად არ გამომიყენებია. სწრაფი mini ამ განხილვის საგანი და production კანდიდატი არ არის.

## Coverage და მეთოდი

დასრულების კრიტერიუმია ერთ run-ში `plan.json` + `parts.png` + `latency.json`-ის არსებობა. stress-ში აღმოჩნდა 6 დაწყებული run, მათგან **5 დასრულებული და ხუთივე რეალურად გახსნილი** (gym 2, sink 3). 12-ნიმუშიანი შეზღუდვა საჭირო არ გახდა. tracking-ში 12 დაწყებული run-იდან **11 დასრულებული და თერთმეტივე რეალურად გახსნილია**: sink/gym/car — original და ორივე shift; chemistry — original და shift_left. სულ გაიხსნა **16 parts.png**, დამატებით gym original და motion_blur `input.png`, რათა ID წარწერით დაფარული მცირე დეტალი შემემოწმებინა.

ყველა დასრულებული run-ის `plan.json`-იდან შედარდა ნაწილების ID/label და ნაბიჯების focus; წაკითხულია latency და კონფიგურაცია. შესაბამისი stress სცენები პირდაპირ შედარდა იმავე სცენის tracking original-ს. კონფიგურაციაშია `gpt-6-astra`, `effort=low`, `max_side=768`; განხილვა ეხება ამ c_visual სერიას და არა სხვა მოდელს ან effort-ს. ქვემოთ მოცემული latency მხოლოდ არსებული ერთეული გაშვებების აღწერაა.

გამოტოვებულია **gym occlusion** და **chemistry shift_right**: snapshot-ში არ აქვთ დასრულების სრული სამეული. ნაწილობრივი parts/first_step არტეფაქტები დასრულებული შედეგის შემცვლელად არ შეფასებულა. car/chemistry-ის stress შედეგები ამ snapshot-ში არ არის; microscope/psychology/laundry-ზე დასკვნა არ ვრცელდება. ფაილებს არ დაველოდე.

## ძირითადი findings

1. **დიდი ნაწილები ძირითადად სწორ ადგილას რჩება, ზუსტი კონტური — ყოველთვის არა.** gym-ის სახელური, ორივე ბალიში და სავარძელი noise/blur-შიც ცნობადია და label-ს შეესაბამება. motion_blur-ზე წონის დასტის p3 კონტური დანაწევრებულია და მთლიან დასტას original-ის მსგავსად აღარ შემოსაზღვრავს; ბალიშის საზღვრებში მიმდებარე ბუნდოვანი არეც ხვდება. sink-ში ორივე ქანჩი და U-მილი ცნობადია; blur-ზე p5-ის მარჯვენა შეერთებასთან კონტური ხვრეტებიანია. dark_noise-ში p5 ზედა ვერტიკალურ მონაკვეთს უფრო ფართოდ მოიცავს, ვიდრე original. სწორ ობიექტთან მიახლოება ზუსტ SAM საზღვარს არ ნიშნავს.
2. **მცირე დეტალების წარმატება შეზღუდულად დასტურდება.** gym-ის ყვითელი p2/p7 original input-ზე ჩანს; blur input-ზე მათ ადგილას ყვითელი ბუნდოვანი კვალი რჩება. parts.png-ის ID ნიშნები თავად მცირე დეტალს ფარავს, ამიტომ მხოლოდ overlay-ით ზუსტ კონტურს ვერ დავადასტურებ. `segmentation.json`-ში p2-ის არაცარიელი მასკა 89-დან 174 პიქსელამდე, p7-ისა 116-დან 246-მდე იზრდება original→blur; ეს მხოლოდ მასკის ზომის ცვლილებაა, არა ხარისხის ქულა. blur plan თავადაც ამბობს, რომ p2 მდებარეობით ყველაზე სავარაუდო სამიზნეა. შესაბამისად, „ქინძისთავი ზუსტად ამოიცნო“ ზედმეტად ძლიერი დასკვნა იქნებოდა.
3. **sink occlusion-ში არარსებული სამიზნის გამოგონება ამ მაგალითში არ ჩანს.** p5-ის ხილული მარცხენა/მარჯვენა მონაკვეთები მონიშნულია, ნაცრისფერ დამფარავ არეს მასკა არ ავსებს; label პირდაპირ აღნიშნავს დაფარულ ქვედა შუა მონაკვეთს. ვედროს ნაბიჯში `focus=[]` და გაფრთხილებაა, რომ დაფარულ ზონას ვედროს ნაცვლად არ მიუთითებს. შუასადების ნაბიჯში `focus=[p5,p4]` რჩება, მაგრამ ტექსტი ზუსტად განასხვავებს მოსახსნელ მილს/შეერთებას უხილავი რგოლისგან; რგოლს ახალი ID არ ენიჭება. ეს ნაწილობრივ ხილულ ობიექტზე მიბმაა, არა დაფარული შუასადების ვიზუალური აღმოჩენა. gym occlusion-ზე იგივე ვერ დასკვნდება, რადგან დასრულებული plan არ გვაქვს.
4. **გაურკვევლობა ტექსტში აღინიშნება, თუმცა focus მაინც შეიძლება დაშვებაზე იდგეს.** sink motion_blur-ის „მოუშვი ქანჩი“ p4-ს ირჩევს, მიუხედავად იმისა, რომ warn-ში წვეთების/სველი კვალის გაურკვევლობა და p1-ის ალტერნატივაა აღნიშნული. ეს c_visual-ის მიერ სავარაუდო სამიზნის არჩევაა და არა გაჟონვის დადასტურება. original/noise/occlusion-ის წვეთებზე დაფუძნებული ტექსტიც დამოუკიდებელ დიაგნოზად არ უნდა ჩაითვალოს.
5. **ნედლი ID მდგრადობა სცენაზეა დამოკიდებული.** sink-ის ხუთი label/ID სამივე tracking კადრსა და სამ stress რეჟიმში ინარჩუნებს როლს. gym original/dark_noise/shift_right-ში p4 მარცხენა ბალიშია, p5 — მარჯვენა; motion_blur-ში ისინი ადგილს ცვლიან, თუმცა label და ვიზუალური მხარე ერთმანეთს შეესაბამება. gym shift_left-ში ერთი სახელური ორ ნაწილად იყოფა (p1/p2), რის შემდეგაც ქინძისთავი p2→p3, წონის დასტა p3→p4, სავარძელი p6→p7 და მარეგულირებელი p7→p8 ხდება. კადრის შიგნით focus შესაბამის ახალ ID-ს იყენებს, მაგრამ კადრებს შორის ძველი ID-ის პირდაპირ გადატანა არასწორი იქნება.
6. **tracking-ის დამატებითი კონტროლი:** car-ის სამივე კადრში p1 ზეთის ხუფსა და p2 ყვითელ რგოლს მიჰყვება; კონტურები შესაბამის უბნებში რჩება. ეს დახურული ღეროს ნიშნულების წაკითხვას არ ადასტურებს — original plan-იც ამბობს, რომ დონე არ ჩანს. chemistry original-ში 9 ნაწილია, shift_left-ში 7: ხილული დამჭერი/შტატივი ცალკე ნაწილებად აღარ შედის; ბიურეტი p3→p2, ონკანი p5→p3, წვერი p6→p4, კოლბა p7→p5 ხდება. წვრილი მინის წვერი და ბიურეტი სურათზე ვიწრო/წყვეტილი კონტურებითაა წარმოდგენილი; ასეთი overlay ზუსტ ოპერაციულ მიბმას თავისთავად ვერ ამტკიცებს. ნაწილების სიის შემადგენლობაც არასტაბილურია, მარტო ნომრები არა.
